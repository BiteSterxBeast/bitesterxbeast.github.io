FAQ

Answers to the questions people ask most about BiteSterxBeast and its tools.

What is BiteSterxBeast?

BiteSterxBeast is a project built by one person — me — with a simple goal: giving new and growing YouTube creators an extra edge with the algorithm, along with the tools and resources to grow more efficiently.

Are Channel Deck and the other tools free to use?

Yes, completely free — no subscriptions, no paywalls, nothing to guarantee. If paid extras ever get added down the line, they'll be purely optional add-ons like custom themes or cosmetic features, never anything that changes the core purpose of these projects.

Why does Channel Deck need my own YouTube Data API key instead of working out of the box?

Right now, Channel Deck runs on your own YouTube Data API key rather than a shared one — that's simply where development currently stands. Down the road, the plan is to remove that requirement so Channel Deck works without needing your own key.

Is my API key or channel data stored anywhere besides my own browser?

No. Your API key and all your channel data stay entirely within your own browser. None of it is stored on or sent to any server I run.

How often does Channel Deck refresh data, and will that cost me API quota?

Refresh frequency is fully in your control via Settings, and quota usage scales with how many channels you're tracking — tracking two channels uses roughly twice the quota of one, five channels roughly five times, and so on. If you're tracking a lot of channels, setting a longer refresh interval helps conserve quota.

Will Extended Studios require me to sign in with my Google or YouTube account?

Nope. Every project here is built to be free to use without linking your Google account.

Is this an official YouTube product, or affiliated with YouTube/Google?

This is not an official YouTube or Google product, and there's no affiliation with either. It's an independent, third-party site built specifically to help creators who need extra support navigating the YouTube Studio algorithm.

Do you run ads or sell user data?

Nope — no ads, and no data collection. There's nothing being gathered to sell.

Can I request a feature or suggest a new tool?

Absolutely — head to the Request a Tool link, which takes you to a quick Google Form where you can submit your idea.

How do I report a bug?

If you run into a bug, don't hesitate to report it — reach out through email or the Discord server, both listed on the Contact page.
