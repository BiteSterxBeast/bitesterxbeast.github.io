Privacy Policy

What this site collects

BiteSterxBeast.github.io is a static site with no server or database of its own. It doesn't run analytics, tracking scripts, or ads, and it doesn't set tracking cookies.

Channel Deck

Channel Deck stores everything — your tracked channels, competitors, notes, settings, and your own YouTube Data API key — locally in your browser's storage. None of it is sent to me or to any BiteSterxBeast server. When Channel Deck fetches data, your browser talks directly to YouTube's API using the key you provided. Clearing your browser's site data for this page will erase everything Channel Deck has stored.

Request a Tool

The "Request a Tool" form is a Google Form. Anything you submit there is stored and processed by Google, under Google's own privacy policy — not mine. I read submissions to decide what to build next.

Third-party services

  • GitHub Pages hosts this site and may log standard access data (like any web host) as part of its own infrastructure, outside my control.
  • YouTube Data API (Google) is called directly from your browser when you use Channel Deck, using your own API key.
  • Google Forms processes "Request a Tool" submissions.
  • Discord handles anything you post or share in the community server.

Each of these is governed by its own provider's privacy policy, not this one.

Children's privacy

This site isn't directed at children under 13, and I don't knowingly collect information from them.
