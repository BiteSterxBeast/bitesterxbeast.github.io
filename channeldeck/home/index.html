Changelog

V0.18

September 1, 2026
  • Added a Tags / Creators switch to the second search bar.
  • Creators mode takes up to three creators and finds other channels making similar content. Give it an @handle, channel URL, or name.
  • It samples each creator’s 15 most recent uploads and builds a style profile from their video tags, titles, and channel keywords, then searches on that profile and constrains it to the category they actually publish in.
  • Videos from the seed creators themselves are filtered out, so results are only other people making that kind of content.
  • With more than one creator, only traits they share are used, so one channel’s quirks can’t skew the results. One creator at a time gives the sharpest profile.
  • The derived profile is shown on screen, so it’s clear what the search actually ran on rather than being a black box.
  • Creator chips warn when a bare name is used instead of an @handle or URL, since a name has no cheap lookup and costs about 100 extra quota units to resolve.
  • The profile is reused while paging, so "Show me more" never pays to re-read the creators’ uploads.

V0.17

August 31, 2026
  • Fixed the Shorts filter pulling in long-form videos. Shorts were being identified by duration alone, so any regular upload under 3 minutes was wrongly counted as a Short.
  • Shorts are now detected by duration and orientation: a video has to be under 3 minutes and vertical (or square) to count. A two-minute landscape upload is now correctly long-form.
  • Search results now hover-explain how each video was classified, and any result classified without orientation data is marked with a dashed badge and a question mark.

V0.16

August 31, 2026
  • Quota tracking is now global: every API call from every tab is counted, and the quota bar reads the same running total whether you are on Tab List, Graph View, Competitors, or Search.
  • Usage is tracked per API key and resets automatically at midnight Pacific, matching when YouTube resets the real allowance.
  • The quota bar now breaks down usage per key, with a colour that shifts from teal to amber to red as a key fills up.
  • Added per-tab quota bar toggles in Settings, so the bar can be switched off on any tab individually.
  • Added per-tab API key assignment in Settings. A tab can be pinned to a specific key, and still rotates onward if that key runs dry.
  • The API keys menu now shows what percentage of each key’s daily quota has been spent.
  • A key that returns a quota-exceeded error is now marked as fully spent, so the bar reflects reality instead of the running estimate.

V0.15

August 31, 2026
  • Added the Search tab: search YouTube by a term plus optional tags, with results ranked by view count.
  • Search filters for sort order, upload time range, long-form vs Shorts, minimum views, region, language, and hiding live streams.
  • Each search pulls a full 50-result page at once, so "Show me more" reveals the next 10 for free and only spends quota once the batch runs out.
  • A one-time warning now appears before your first search, explaining that a search costs roughly 101 of a key's 10,000 daily quota units.
  • Added a daily search quota meter, and results can be added straight to Competitors from the search list.

V0.14

August 11, 2026
  • Fixed a security issue where channel titles, handles, and typed-in channel names could inject raw HTML into the page instead of being displayed as plain text.
  • Fixed milestone alerts so that jumping across multiple milestones in a single refresh (e.g. crossing both 500 and 1,000 subs at once) now correctly reports the highest milestone reached instead of the lowest.
  • Per-card "Auto-refresh subs" now only refreshes channel-level stats (subs/views/videos) instead of silently re-fetching the full upload list and every video's stats, matching what the label says and cutting quota usage substantially.
  • Video view-history used for VPH calculations is now automatically pruned once a video ages out of the 365-day tracking window, instead of growing forever in local storage.
  • Legacy /c/ and /user/ channel URLs now try an exact username lookup before falling back to a fuzzy search, reducing cases where the wrong channel got added.
  • "Dead Video" label in VPH stats no longer appears on brand-new uploads that simply haven't accumulated hourly view data yet — it's now reserved for videos with genuinely stalled view growth.
